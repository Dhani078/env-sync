CONTRIBUTING TO env-sync

Guidelines

1. Single Contributor Model
Maintained by Dhani078.

2. Code Standards
- Zero external dependencies: Standard library only.
- 200 lines maximum per source file.
- Node.js >= 20.0.0 LTS.
- Strictly no markdown hash headers and no asterisks in documentation.

3. Testing Requirements
Must pass automated unit tests covering multiline env files, quoted values, and complex code expressions.
