SECURITY POLICY: env-sync

Secret Protection Guarantees

- No Secret Copying: env-sync never copies values from .env into .env.example. Only keys are copied, and values are replaced with sanitized placeholder strings.
- 100 Percent Local: Runs entirely offline on local files.
